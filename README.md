# English Tube (개인 공부용)

유튜브 영어 영상을 **코스(순서대로 보는 레슨 묶음)**로 정리하고, 영상 아래에 **영어·한글 자막을 문장 단위로** 띄워 공부하는 앱이에요.
개인 공부용이라 자막은 `youtube-transcript-api`로 가져와요. 영상 자체는 유튜브 공식 플레이어로 재생돼요.

## 실행

```bash
cd ~/Desktop/AI/app/english_tube
./start          # http://localhost:8765 이 브라우저에서 열림 (종료: Ctrl+C)
```

## 휴대폰에서 보기

1. Mac에서 `./start`를 실행하면 터미널에 **휴대폰 주소**(예: `http://192.168.x.x:8765`)와 **QR코드**가 나와요.
2. 휴대폰을 **Mac과 같은 와이파이**에 연결하고, 카메라로 QR코드를 찍거나 주소를 직접 입력하세요.
3. 처음 실행할 때 Mac에서 "python이 들어오는 연결을 허용할까요?"라는 창이 뜨면 **허용**을 누르세요.
4. 앱처럼 쓰려면 홈 화면에 추가하세요.
   - 아이폰 Safari: 공유 버튼 → **홈 화면에 추가**
   - 안드로이드 Chrome: ⋮ 메뉴 → **홈 화면에 추가**

휴대폰 화면에서는 영상이 위에 고정되고, 지금 문장이 바로 아래에 강조되며, 조작 버튼(이전·재생·다시·다음·반복·쉐도잉·저장)은 아래쪽 바에 있어요.

- Mac이 켜져 있고 `./start`가 실행 중일 때만 접속돼요. 집 밖에서는 안 돼요.
- 진도와 저장 문장은 기기마다 따로 저장돼요. 휴대폰과 Mac의 진도는 공유되지 않아요.

## 코스 추가

```bash
./tube add "코스 이름" <URL> [URL ...]
./tube add "BBC 6분 영어" "https://www.youtube.com/playlist?list=..." --limit=20
./tube add "미드 표현" https://youtu.be/xxxx https://youtu.be/yyyy
```
- 영상, 재생목록, 채널 URL 모두 가능해요. 같은 코스 이름으로 다시 실행하면 레슨이 뒤에 이어 붙어요.
- 추가한 뒤 브라우저를 새로고침하면 바로 보여요.
- `./tube list`: 코스 목록 · `./tube remove "이름"`: 코스 삭제 · `./tube refresh <videoId>`: 자막 다시 받기

## 한글 자막은 어디서 오나

| 순서 | 출처 | 비고 |
|---|---|---|
| 1 | 영상에 있는 사람이 만든 한국어 자막 | TED 등은 대부분 있음, 품질 좋음 |
| 2 | 유튜브 자동번역 | 현재 자주 막혀 있음 |
| 3 | Claude API (`ANTHROPIC_API_KEY` 환경변수가 있을 때) | 유료 API 키 필요 |
| 4 | 없음 → 영어만 표시 | 홈 화면에 "영어 자막만"으로 표시돼요 |

**API 키 없이 번역 채우기:** Claude Code에서 *"english_tube 한글 없는 자막 번역해서 채워줘"*라고 하면 돼요.
(`./tube missing`으로 대상을 찾고, `번호<TAB>번역` 파일을 만든 뒤 `./tube setko <videoId> <파일>`로 넣는 방식이에요.)

## 학습 화면 기능

- **자막 모드:** 영+한 / 영어만 / 한글만 / 가리기 (가리기는 문장을 클릭하면 보여요, 듣기 테스트용)
- **문장 이동:** 스크립트 문장을 클릭하면 그 문장으로 이동, ◀ 이전 / ↺ 다시 / 다음 ▶
- **🔁 반복:** 현재 문장을 무한 반복
- **⏸ 쉐도잉:** 문장이 끝날 때마다 자동으로 멈춤 → 따라 말하고 Space로 계속
- **☆ 저장:** 복습 문장으로 저장, 홈 화면 하단에서 모아보기
- **속도:** 0.75x / 1x / 1.25x
- **진도:** 레슨 완료 체크, 이어보기 위치 자동 저장, "이어서 학습" 버튼
- **단축키:** Space 재생/정지 · ←/→ 문장 이동 · ↓ 다시 · R 반복 · P 쉐도잉 · S 저장 · 1~4 자막 모드

진도와 저장 문장은 브라우저(localStorage)에 저장돼요. 브라우저 데이터를 지우면 사라지고, 다른 브라우저와는 공유되지 않아요.

## 파일 구조

```
tube / tube.py      코스·자막 수집 도구 (.venv 사용)
start / serve.py    학습 앱 실행 (휴대폰 주소·QR 표시)
manifest.json icon-*.png  홈 화면 추가용
index.html app.js style.css   학습 앱
data/courses.json   코스 목록과 순서 (직접 편집해서 순서를 바꿔도 됨)
data/subs/<id>.json 영상별 문장 자막 {s, e, en, ko}
```

## 알려진 한계

- 자동 생성 영어 자막(사람이 만든 자막이 없는 영상)은 구두점이 없어서 문장 나눔이 덜 자연스러워요. 가능하면 자막이 잘 달린 채널을 고르세요(BBC Learning English, TED 등).
- 같은 IP로 너무 많이 요청하면 유튜브가 자막 요청을 잠시 막을 수 있어요. 큰 재생목록은 `--limit`으로 나눠 받으세요.
